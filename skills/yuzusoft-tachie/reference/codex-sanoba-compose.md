# 任务：合成《魔女的夜宴》完整立绘（当前缺脸部）

## 背景
上一轮已成功解密提取游戏资源：
- `E:\tmp\sanoba-final\` — 解密+还原文件名的原始文件（11 个角色文件夹：１－寧々、２－めぐる、３－紬、４－憧子、５－和奏、６－七緒、７－佳苗、８－秀明、９－太一、１０－アカギ、１１－越路；含 .pbd / .sinfo / .tlg / .csv / .tjs 文件）
- `E:\tmp\sanoba-png\` — 全部 TLG 转好的 PNG（1493 张，同样按角色分文件夹）
- 你上一轮的工作脚本在 `E:\tmp\sanoba-work\`（cx_engine.py、hx_decrypt.py、hx_parse.py 等）

## 问题
大尺寸的 PNG（如 `寧々a_0_1875.png`，640x1717）看起来是完整立绘，**但脸部是空的**——眼睛、嘴巴、眉毛全部缺失（只有光滑的皮肤色）。原因：这是柚子社的运行时图层系统，脸部器官（眼睛/嘴/眉）是独立的小图层文件（如 `寧々a_0_2354.png` 这类小图），游戏运行时按 `.pbd` 文件里的定义（layer_id + 坐标）动态叠加。

## 目标
按 `.pbd` 文件的图层定义，把身体大图 + 脸部器官图层正确合成，输出**带脸的完整立绘**：

- 输出到 `E:\tmp\sanoba-composed\`，按角色分文件夹
- 每个角色至少 1 张默认表情的完整立绘（多套服装更好）
- PNG 格式，保留透明背景

## 线索
1. `.pbd` 文件（如 `E:\tmp\sanoba-final\１－寧々\寧々a.pbd`）是二进制的图层定义，含 layer_id 和坐标。社区教程（kungal.com/topic/2670 评论#1，做立绘的人说）："通过 pbd 文件（含 layer_id 图 id）配前缀文件名可快速收集全部角色 TLG 立绘"——即 `寧々a_<layer_id>.png` 是 pbd 里引用的图层
2. `E:\tmp\garbro2\GARbro.GUI.exe`（GARbro2）**内置了立绘合成器**：右侧面板有「叠加」「模式」「添加选中」「导出」按钮，能自动合成这类分层立绘。它的源码在 https://github.com/crskycode/GARbro 或 https://github.com/UserUnknownFactor/GARbro2 里（搜 psb/pbd/PsDiagramFile/立绘相关代码），可以参考其合成算法（怎么解析 pbd、坐标怎么对齐、哪些图层组成默认表情）
3. `.sinfo` 文件可能是 sprite info（尺寸/布局信息）
4. 大图（`寧々a_0_NNNN.png` 的 `_0_` 前缀是 1x 版本，非 `_0_` 是 2x 版本——注意图层混合时要用同一倍率）
5. 图层 Z 序：身体在下，眼睛/嘴/眉在上

## 验收标准
1. `E:\tmp\sanoba-composed\` 里的立绘**有完整的脸**（眼睛、嘴、眉毛都在正确位置）
2. 至少覆盖：寧々、めぐる、紬、憧子、和奏、七緒、佳苗（7 名女主角），其他角色有更好
3. 图层对齐正确（五官不能错位）
